# GoHaode 社区与反馈中心 🇨🇳

[English](README.md) | [简体中文](README-zh.md)

欢迎来到 **[GoHaode（gohaode.com）](https://gohaode.com)** 官方公开问题反馈仓库。

GoHaode（Go好的）是给来华外国游客用的免费、离线优先的落地生存工具：免签与 240 小时过境自查、带拼音的大字中文出示卡（打车、点菜、住店、看病）、支付与交通排障、双时区时钟和紧急电话。由 GateHop 团队制作。

---

## 💡 如何反馈

- 🛂 **纠正签证或政策信息**：[提交政策纠错](https://github.com/jviewes-commit/gohaode-feedback/issues/new?template=01_policy_correction.md)  
  *免签入境、240 小时过境、海南免签、支付或交通规则。请附官方来源（国家移民管理局、外交部、使领馆）。*
- 🀄 **纠正或建议出示卡**：[提交卡片反馈](https://github.com/jviewes-commit/gohaode-feedback/issues/new?template=02_card_content.md)  
  *中文、拼音或译文有误，或你需要却找不到的说法。*
- 🐛 **提交 Bug**：[提交 Bug 报告](https://github.com/jviewes-commit/gohaode-feedback/issues/new?template=03_bug_report.md)  
  *界面错位、离线不可用、时区错误、安装问题等。*
- 💡 **提出新功能**：[提交功能建议](https://github.com/jviewes-commit/gohaode-feedback/issues/new?template=04_feature_request.md)

没有 GitHub 账号？请发邮件到 [support@gohaode.com](mailto:support@gohaode.com)。

---

## 🔍 我们怎么核对事实

- 签证与入境规则只采用官方来源：国家移民管理局、外交部和中国驻外使领馆。
- 能否入境以边检现场判定为准。GoHaode 仅供参考，不构成法律意见。
- 纠错会先对照官方公告核实再上线。详见[关于 GoHaode](https://gohaode.com/zh-CN/about/)。

---

## 🔒 隐私

- **无需注册，没有广告。** 你保存的内容只留在手机上。
- **只统计匿名访问量**（Cloudflare Web Analytics），不用 Cookie，不跨站追踪。
- **打开过一次即可离线使用**，包括出示卡和紧急电话。
- 请勿在 issue 里贴护照号、手机号或订单号。
- 完整说明：[隐私与安全](https://gohaode.com/zh-CN/#/privacy)
